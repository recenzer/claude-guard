# Claude Guard

Защита Claude Desktop от утечки трафика мимо VPN. Служба Windows блокирует выход Claude в интернет через системный firewall, пока VPN-туннель не пройдёт активную проверку. Если VPN упал, Claude блокируется за секунды, а при необходимости закрывается. Когда VPN вернулся и стабилен, доступ открывается снова.

> **Важно.** Настройки по умолчанию рассчитаны на VPN-клиент **Happ** (адаптер `happ-tun`). Для другого VPN нужно поправить `config.json`, см. [Настройка](#настройка).

## Как это работает

- Для всех `.exe` пакета Claude Desktop создаются правила Windows Firewall (через COM API, без PowerShell).
- На физических интерфейсах (LAN, Wi-Fi) Claude заблокирован **всегда**. Выйти в сеть он может только через TUN-адаптер VPN.
- Если туннель не проходит проверку, блок расширяется на все интерфейсы.
- Проверка активная: каждые 2 с выполняется TCP + TLS-рукопожатие к `api.anthropic.com` и `www.cloudflare.com`, сокет привязан к адресу TUN. Один сбой не блокирует Claude, нужна серия.
- Состояние по умолчанию: **заблокировано**. Разрешение выдаётся только после серии успешных проверок.
- Сторожевая задача раз в минуту проверяет службу. Если служба недоступна, включается аварийный блок.

## Требования

- Windows 10 / 11, x64
- Включённый Windows Firewall
- Claude Desktop (пакет MSIX)
- VPN-клиент с TUN-адаптером (по умолчанию Happ)
- Права администратора для установки

.NET устанавливать не нужно, сборка самодостаточная.

## Установка

1. Скачайте `ClaudeGuard-<версия>-win-x64.zip` со страницы [Releases](../../releases/latest).
2. Распакуйте архив в любую папку (не в `Program Files`).
3. **Включите VPN** и дождитесь, пока он подключится: установщик проверяет туннель.
4. Запустите `scripts\install.cmd`. Согласитесь на запрос UAC.

Установщик сам:
- сохранит резервную копию правил firewall и конфига;
- скопирует файлы в `C:\Program Files\ClaudeGuard`;
- проведёт самопроверку (туннель работает, а прямой выход мимо VPN заблокирован);
- создаст службу `ClaudeGuard` (автозапуск) и задачи `ClaudeGuardUi`, `ClaudeGuardWatchdog`;
- при любой ошибке откатит всё назад, и Claude останется разблокированным.

Windows SmartScreen или антивирус могут предупредить о неподписанных файлах. Это ожидаемо: сборки не подписаны сертификатом. Исходный код открыт, при желании соберите сами (см. ниже).

## Использование

После установки значок Claude Guard появляется в трее, окно открывается из меню Пуск. Закрытие окна сворачивает его в трей, защита продолжает работать.

| Цвет | Состояние |
|---|---|
| Зелёный | VPN проверен, Claude разрешён только через туннель |
| Синий | идёт проверка, Claude заблокирован |
| Жёлтый / красный | VPN недоступен, Claude заблокирован (и закрыт через 5 с) |
| Красный | защита отключена вручную |

Кнопка «Отключить защиту» снимает правила firewall и требует подтверждения администратора (UAC). Включить обратно можно той же кнопкой.

Журналы: `C:\ProgramData\ClaudeGuard\logs`.

## Настройка

Файл `C:\ProgramData\ClaudeGuard\config.json` создаётся при первом запуске. После правки перезапустите службу:

```powershell
Restart-Service ClaudeGuard
```

| Параметр | Значение по умолчанию | Описание |
|---|---|---|
| `tunAlias` | `happ-tun` | имя TUN-адаптера (см. `Get-NetAdapter`) |
| `tunExpectedPrefix` | `172.18.0.0/30` | подсеть, в которой должен быть IP адаптера; пустая строка отключает проверку |
| `requiredProcesses` | Happ, happd, sing-box, xray | процессы VPN, которые должны быть запущены |
| `probeTargets` | api.anthropic.com, www.cloudflare.com | куда проверяется туннель |
| `killClaudeOnFailure` | `true` | закрывать Claude при потере VPN |
| `killDelaySeconds` | `5` | задержка перед закрытием |
| `autoRestartClaude` | `true` | запускать Claude после восстановления VPN |

Для другого VPN укажите свои `tunAlias`, `tunExpectedPrefix` и `requiredProcesses`. Если установщик не проходит самопроверку, проверьте эти три параметра.

## Удаление

Запустите `scripts\uninstall.cmd` (или тот же скрипт из распакованного архива). Он удалит службу, задачи, правила firewall и файлы программы. Журналы и конфиг останутся, если не указать `-PurgeData`.

Если служба сломалась и Claude остался заблокированным:

```powershell
& "C:\Program Files\ClaudeGuard\ClaudeGuard.Service.exe" --remove-rules
```

(в PowerShell от имени администратора)

## Сборка из исходников

Нужен [.NET SDK 10](https://dotnet.microsoft.com/download).

```powershell
scripts\build.ps1      # разработческая сборка в dist\
scripts\package.ps1    # самодостаточный релизный zip в release\
```

Релиз на GitHub собирается автоматически при пуше тега `v*` (`.github/workflows/release.yml`).

## Ограничения

- Защищает только Claude Desktop (пакет MSIX), не браузер и не Claude Code в терминале.
- Только IPv4: проверка и привязка сокета идут по IPv4.
- Защита основана на правилах Windows Firewall. Администратор может их изменить: службы это обнаружит и восстановит правила, но гарантий против локального администратора нет.
